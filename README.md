# ✅ TaskFlow

**Organiza tus tareas, cumple tus metas.** Una pequeña aplicación web para registrar pendientes, ver sus fechas en un calendario y llevar el control de lo que ya realizaste.

## ✨ ¿Qué puedes hacer?

- Crear tareas con título, descripción, fecha límite y prioridad.
- Marcar tareas como pendientes o realizadas.
- Consultar un calendario con indicadores en días que tienen tareas.
- Ver próximas fechas de vencimiento y avisos para tareas cercanas.
- Filtrar por todas, pendientes o realizadas.
- Guardar automáticamente las tareas en el navegador.

## ▶️ Cómo abrirlo

Abre `index.html` en un navegador moderno. No requiere instalación de dependencias ni servidor para este prototipo.

> Las tareas se guardan en el almacenamiento local del navegador en el que abras la aplicación. Si borras los datos del navegador, también se borrará este historial.

## 📁 Estructura

```text
TaskPlanning/
├── index.html       # Interfaz de la aplicación
├── css/
│   └── style.css    # Estilos y diseño adaptable
├── js/
│   └── app.js       # Tareas, calendario y almacenamiento local
└── README.md
```

## 🧭 Uso rápido

1. Selecciona **Nueva tarea** y completa el formulario.
2. Guarda la tarea para verla en la lista y el calendario.
3. Usa la casilla junto a una tarea para marcarla como realizada.
4. Consulta **Próximos vencimientos** para revisar las fechas pendientes.

## 🛠️ Tecnologías

HTML, CSS y JavaScript, sin librerías externas. La fuente visual se carga desde Google Fonts cuando hay conexión a internet.
